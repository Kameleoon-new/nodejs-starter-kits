# Kameleoon Node.js Starter Kits

Minimal, runnable examples of the [Kameleoon Node.js SDK](https://docs.kameleoon.com/developer-docs/sdks/web-sdks/nodejs-sdk). Each kit is a self-contained project in its own folder, with its own README.

| Kit | What it shows |
| --- | --- |
| [hybrid-starter-kit](hybrid-starter-kit) | Hybrid mode with Express: the Node.js SDK and `engine.js` together, with server-side and engine-side exposure tracking, and visitor code and consent synchronization. |

## Requirements

- Node.js 20 or later
- A Kameleoon account with a project site code and API credentials

## Use a kit

```bash
git clone https://github.com/Kameleoon-new/nodejs-starter-kits.git
```

```bash
cd nodejs-starter-kits/hybrid-starter-kit
```

Then follow the README of the kit.
